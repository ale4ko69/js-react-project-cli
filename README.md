# js-react-project-cli

A command-line interface (CLI) tool for quickly scaffolding new React projects based on the [js-react-project](https://github.com/ale4ko69/js-react-project) template.

## Features

- Creates a new React project with a modern, opinionated structure
- Sets up a complete development environment with Vite
- Includes Redux, React Router, and other essential libraries
- Configures ESLint and Prettier for code quality
- Includes SASS support for styling
- Sets up i18next for internationalization
- Initializes a fresh Git repository
- Installs all dependencies automatically

## Installation

```bash
# Install globally
npm install -g js-react-project-cli

# Or use npx to run without installing
npx js-react-project-cli <project-name>
